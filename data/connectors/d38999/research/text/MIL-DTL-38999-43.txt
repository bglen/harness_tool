REQUIREMENTS:

  Dimensions and configurations: See figure 1.

  Interface dimensions shall conform to MIL-DTL-38999.

  This connector mates with MIL-DTL-38999/46 and /47.

  Main key color: Blue.

  For insert arrangements: See MIL-STD-1560.

  Part or Identifying Number (PIN) example:

                      D38999/    43   N    B     35    P    N


 DOD no. prefix

  Specification sheet no.

  Class

  Shell size code

  Insert arrangement

  Contact style
   P – Pin, Solder cup.
   X – Pin, Eyelet.


  Polarizing position:
  N is required for normal position.

For contact termination: See MIL-DTL-38999.
